gopgql

One annotated GraphQL SDL document → PostgreSQL 19 SQL/PGQ. This is M1: the SDL below is parsed and validated, an initial goose migration is generated, and the GraphQL query is compiled to a GRAPH_TABLE statement — all running entirely in your browser as compiled Go (WebAssembly), the real sdl+generator+compiler packages, no server and no JavaScript re-implementation.
