gopgql

One annotated GraphQL SDL document → PostgreSQL 19 SQL/PGQ. Edit the schema, query and variables on the left; gopgql generates the goose migration and compiles the query to a GRAPH_TABLE statement with ordered bind parameters. It runs entirely in your browser as compiled Go (WebAssembly) — the real sdl+generator+migrate+compiler packages, no server and no JavaScript re-implementation. Nothing is hardcoded: every output below is generated from your input.

There is no database here, so query results can't be shown — only the generated SQL. Shaping rows into nested JSON (with parent dedup) happens at execution time against PostgreSQL; it is covered by the godog integration suite, not this browser demo.
