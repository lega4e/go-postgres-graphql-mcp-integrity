gopgql

One annotated GraphQL SDL document → PostgreSQL 19 SQL/PGQ. This is M3: the two SDL revisions still drive the folded delta migration (ALTER TABLE plus a recreated property graph), and the new one-hop query panel below compiles a nested GraphQL query with a bound variable to a single GRAPH_TABLE MATCH — showing the ordered $1 placeholder — then shapes sample rows into the nested JSON response, deduplicating the parent across the one-to-many fan-out. It all runs entirely in your browser as compiled Go (WebAssembly) — the real sdl+generator+migrate+compiler+shape packages, no server and no JavaScript re-implementation.
