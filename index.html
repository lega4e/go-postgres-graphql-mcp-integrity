gopgql

One annotated GraphQL SDL document → PostgreSQL 19 SQL/PGQ. This is M2: edit the two SDL revisions below and gopgql generates the initial goose migration for the first, then folds it back into a schema and diffs it against the second to emit a delta migration (ALTER TABLE plus a recreated property graph). The query compiles to a GRAPH_TABLE statement against the revised SDL. It all runs entirely in your browser as compiled Go (WebAssembly) — the real sdl+generator+migrate+compiler packages, no server and no JavaScript re-implementation.
